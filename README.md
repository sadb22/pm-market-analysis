# PM Job Market Analysis

## Description
This project analyzes the job market for Junior and Intern Product Manager positions
based on open job vacancy data.

The goal is to identify key skills, requirements, and trends
for building a strong career path in product management.

## Current Stage
- Manual data collection
- Data structuring in Excel
- Preparing automated parsing

## Tech Stack
- Python
- Excel
- SQL (in progress)
- GitHub
- VS Code
